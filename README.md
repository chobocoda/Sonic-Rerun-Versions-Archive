# Sonic Rerun Versions Archive
This is an archive of all versions of the original Sonic Rerun from 2019 to 2020.
The last version is v1.2, which was a patch to fix some issues.

## Information

The Extras folder contains projects that were not a main part of Sonic Rerun's development, but were "still the life of the party".
- This contains a "50Hz" patch, to fix music slowdown (via replacing the sound driver with the original SMPS 68k driver).
- This also contains the "Sonic Rerun 2" project, which was in the initial planning stages but was cancelled early on.
